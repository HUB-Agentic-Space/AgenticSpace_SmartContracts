🧮 Cálculo para Novo Estágio

Quando for necessário ajustar para um novo preço alvo P_target = CAS/POL:

1. Mantendo a constante do produto k = CAS_atual × POL_atual
2. Novas reservas ideais em um par V2:
  CAS_novo = √(k × P_target)
  POL_novo = √(k / P_target)
3. Quantidade a adicionar/remover:
  ΔCAS = CAS_novo − CAS_atual
  ΔPOL = POL_novo − POL_atual

Positivo = adicionar liquidez; negativo = remover liquidez (via swap ou removeLiquidity).
